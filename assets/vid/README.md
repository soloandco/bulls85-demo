# 홈 영상 클립 보관

## 올리는 법
시댄스에서 만든 영상을 **이 폴더에 그대로** 두면 된다. 파일명은 아무거나 괜찮다.
클립 순서만 알려 주면(예: "2번 나왔어") Claude가 아래 처리를 한다.

## Claude가 하는 처리
1. 스크롤 재생용으로 다시 인코딩 → `clipN.mp4` (소리 제거, 키프레임 촘촘하게)
2. 첫 프레임 → `clipN-still.webp` (영상 로딩 전에 보이는 정지 화면)
3. 마지막 프레임 → `../seams/clipN-last.png` (**다음 클립의 시작 이미지로 쓴다**)
4. 홈 화면의 해당 장면을 테스트 화면에서 실제 클립으로 교체

## 현재 상태 (2026-08-23)
- clip1~6 전부 붙어 있고 홈에서 끝까지 이어진다
- **나중에 실제 사진 기반으로 다시 만든다** (2026-08-23 사용자). 방향은 「회원들의 직업」.
  화질 개선(clip3·clip6)은 하지 않는다. 사진 수집이 선행 조건이라 지금 영상은 그대로 둔다
- 교체 방법: 새 클립을 이 폴더에 두고 몇 번인지 알려 주면 된다. 코드는 손댈 것이 없다
